How to shop from the spreadsheet

Use the item ID to find a listing again and write down the size, color and price you want to compare.

  1. Open the listing and select your variant

    Check the price again after selecting a size and color. Save the listing URL and the seller’s variant name so you can confirm both at checkout.

  2. Compare measurements in centimeters

    For shoes, compare foot or insole length using the seller’s stated method. For tees and hoodies, measure chest width and body length on a garment you own. For jackets, also check sleeve length. For bags, compare interior dimensions with what you plan to carry.

  3. Review warehouse QC photos when available

    Compare the photographed item with your selected variant. Look for a visible size label, clear measurements and condition details. Ask about an exchange deadline before approving shipment if something differs.

  4. Estimate the delivered cost

    Add the selected item price, domestic shipping, any agent or payment fees, international shipping and applicable import charges. Check the route’s billed weight and compare quotes in the same currency.

HipoBuy spreadsheet FAQ

What is a HipoBuy spreadsheet?

It is a browsable directory of product listings. This page uses a selection from HipobuyFind, with product categories, source item IDs and listed prices for quick comparison.

Where do the two homepage buttons go?

Both buttons open the HipobuyFind homepage. The catalog cards open the individual HipobuyFind listings.

Are the catalog photos warehouse QC photos?

The catalog cards show images from the source listings. If your agent provides warehouse quality control photos, use those to inspect the specific item before approving shipment.

How do I compare shipping options?

Use the same destination and parcel dimensions for each quote. Compare billed weight, restrictions, tracking and any fees shown for the route.
